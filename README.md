# product-ppt

一个可复用的 Codex Skill：把产品介绍、商业计划或项目资料做成一套**以图为主、文字辅助、可原生编辑**的中文产品路演 PPT（16:9 PPTX）。

适用于产品路演、竞赛答辩、创业融资、项目介绍等需要完整叙事的产品演示；也用于对已有 deck 做整页重写、视觉换版或叙事重排。

## 核心原则

- **以图为主、文字辅助**：每页图片承担主要表达（约占 60–70% 版面），但图片内不含可读文字、logo 或虚构数据，所有文字保持原生可编辑。
- **完整句子叙事**：正文用可以照读的中文完整句子，不用关键词堆砌代替解释。
- **页眉系统统一**：每页四字板块名 + 青蓝强调短线 + 一行子标题 + 细分隔线，全片一致。
- **事实分层**：现状、进行中、目标数字明确分开，绝不混写；每项声明可追溯到用户素材。
- **逐页渲染验收**：交付前把每一页渲染成图片逐页检查裁切、碰撞、对比度与层级。

## 工作流概览

1. 先建来源台账（现状 / 目标 / 待办 / 禁用数字）。
2. 先写叙事顺序，再写每页完整文案，最后才做视觉。
3. 图片两条路：产品场景与技术配图用图像模型批量生成（同一套色调与光影，2K 出图）；真实竞品 / 合作厂商图用真实浏览器从图片搜索页截取并标注来源。
4. 原生图层搭建幻灯片，长句手工断行，不靠自动缩字。
5. 双重 QA：事实叙事 pass + 渲染逐页 pass，修到干净为止。

## 目录结构

```
product-ppt/
├── SKILL.md                          # 主工作流
├── agents/openai.yaml                # 界面元数据
├── references/
│   ├── content-playbook.md           # 叙事架构与中文文案规则
│   ├── visual-and-image-system.md    # 视觉体系与生图提示词公式

└── scripts/
    ├── build_contact_sheet.py        # 生图批次拼接触摸板，便于人工审图
    └── extract_pptx_text.py          # 导出后抽取全部幻灯片文字做文案审计
```

## 使用方式

把这个目录放到 Codex 的 skills 目录（如 `~/.codex/skills/product-ppt`），之后直接说「用 product-ppt 把这份资料做成路演 PPT」即可触发。也可以在对话里引用：`$product-ppt`。

本 skill 沉淀自「知笔 · AI 学习智能体」25 页图像版路演 PPT 的完整制作与多轮返工经验。
